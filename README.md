# Poker Helper для Android

Приложение на Kotlin и Jetpack Compose. Минимальная версия Android — 10 (API 29).

## Что уже есть
- Выбор двух карт игрока и общих карт на столе.
- Расчёт комбинации, примерной вероятности победы, шансов банка и математического ожидания колла.
- Подсчёт карт, которые могут улучшить текущую комбинацию.
- Таймер турнирных уровней с автоматическим удвоением блайндов.
- Захват экрана только после подтверждения пользователя в системном окне Android.
- Распознавание видимого текста с помощью Google ML Kit.
- Плавающее окно с результатами распознавания.
- Модуль расчёта позиций за столом, если известны занятые места и положение дилера.

## Как установить
1. Открой вкладку Actions в репозитории GitHub.
2. Выбери последний успешный запуск сборки.
3. В разделе Artifacts скачай архив `PokerHelper-APK`.
4. Распакуй архив и установи APK на телефон.

## Как включить распознавание экрана
1. Открой приложение и нажми **«Начать распознавание»**.
2. Если Android попросит разрешение на отображение поверх других приложений, открой настройки и разреши его.
3. Вернись в Poker Helper и снова нажми **«Начать распознавание»**.
4. Подтверди системный запрос Android на захват экрана.
5. На экране появится плавающее окно с текстом, который удалось распознать.
6. Чтобы остановить захват, нажми **«Остановить»**.

Android показывает системный индикатор и постоянное уведомление, пока захват экрана активен.

## Калибровка стола PPPoker
На используемом пользователем расположении стола нижнее место всегда принадлежит Hero (пользователю). Детектор должен привязывать карты Hero к нижней зоне стола, а не пытаться определять Hero по имени или аватару. Это правило калибровки; автоматический детектор карт и кнопки дилера всё ещё требует реализации.

## Важно: текущие ограничения
Текущая версия умеет захватывать экран и распознавать текст, но пока не распознаёт надёжно изображения карт, аватары, фишки и кнопку дилера. Поэтому позиции игроков ещё не определяются автоматически по одному скриншоту. Для этого необходим отдельный модуль компьютерного зрения и проверка на нескольких примерах стола PPPoker.

Расчёт эквити — приблизительная симуляция против случайной руки соперника, а не профессиональный покерный солвер. Используйте приложение как тренировочный прототип и перепроверяйте результаты.
